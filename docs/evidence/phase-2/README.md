# شواهد فاز ۲ — رویداد، هشدار زنده، وب‌هوک

- `verification_summary.txt`: آزمون‌ها و تحلیل هر دو برنامه، `php -l`، selftestها و مقایسهٔ عکس‌برداری پایان فاز ۲.
- `events_selftest_output.json`: ۶۱ بررسی، از جمله:
  - rollback سند ⇒ رویدادی نمی‌ماند؛ پردازشگر دو بار ⇒ هر رویداد یک بار؛ قفل گرفته‌شده ⇒ busy.
  - HMAC با بردار مرجع؛ رد نشانی‌های خصوصی؛ زمان‌بندی تلاش مجدد؛ ۲۰ شکست ⇒ غیرفعال + هشدار.
  - هشدار موجودی کم و فروش زیر بها (و پنهان بودن برای کاربر بدون «مشاهدهٔ قیمت»).
- `sample_webhook_request.txt`: نمونهٔ درخواست وب‌هوک با امضای درست (کلید نمونه) و روش بررسی در گیرنده.
- `hook_overhead.json`: هزینهٔ قلاب جدید روی هر درخواست نوشتنی (قاعدهٔ ۹). با پرچم خاموش یک خواندن تنظیمات است. با رویداد روشن حدود ۱ میلی‌ثانیه در sqlite است و عدد MySQL را باید روی هاست اندازه گرفت.
- **معیار پذیرش «وب‌هوک آزمایشی به نشانی آزمایشی می‌رسد»:** نیاز به سرور واقعی و یک نشانی https عمومی (مثلاً webhook.site) دارد. بعد از بارگذاری، از «وب‌هوک‌ها ⇐ ارسال آزمایشی» استفاده کنید.
- **تصویر صفحه:** گرفته نشد (برنامه به سرور وصل نبود).
